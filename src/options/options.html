    About

    Keurweb — Keep Your Web

    Version 1.0.0

    Keurweb keeps your websites working for a long time — no idle disconnects, no session timeouts, no frozen or discarded tabs. All locally, with no data collection.

    • 💓 Session heartbeats keep server sessions warm
    • 🖱️ Anti-idle activity simulation
    • 🧊 Anti-discard sweep for Brave's Memory Saver
    • 🚑 Auto-reconnect with backoff for dead tabs
    • 🌐 Per-site configuration with global defaults
    • 🌱 Subdomain rules — protect a whole site family at once

    Keyboard shortcut: Alt+Shift+K toggles the active site. Change it at brave://settings/commands or chrome://extensions/shortcuts.

    Languages: English · Tiếng Việt (follows your browser language)
